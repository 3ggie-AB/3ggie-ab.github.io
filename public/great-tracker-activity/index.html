Cara Memasang di Google Chrome

Hanya membutuhkan 4 langkah mudah tanpa perlu compile ulang.

1
Unduh Berkas ZIP

Klik tombol Unduh ZIP di atas dan ekstrak berkas great-tracker-activity.zip ke folder laptop Anda.

2
Buka chrome://extensions

Ketik chrome://extensions di bilah URL browser Chrome Anda, lalu tekan tombol Enter.

3
Aktifkan Developer Mode

Nyalakan toggle switch Developer mode di pojok kanan atas halaman ekstensi Chrome.

4
Load Unpacked Folder

Klik tombol Load unpacked di kiri atas dan pilih folder hasil ekstrak. Ekstensi siap digunakan!
